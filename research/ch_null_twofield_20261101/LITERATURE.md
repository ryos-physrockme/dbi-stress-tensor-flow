# DBI の null 勾配における CH 連鎖律と既存公式の照合

調査日：2026年11月1日（UTC）。この段階では二成分電磁場の検算に加え、既存の行列恒等式を使って一般の null 勾配について CH 連鎖律中の勾配方向の収縮を消去する。

## 結論と前段階からの評価の変更

**一般 null 配置での消去は、既存原稿の行列式・特性多項式の恒等式から直接導ける。新しい不変量公式や独立の新定理ではない。** 前段階では次の問題として残していたが、原稿本文の該当節と付録を照合した結果、すでに必要な一般的代数構造と符号の議論が揃っていると確認した。今回の追加は、CH 連鎖律との接続を明記し、二成分族での計量補正と相殺条件を再現可能に検査した点にある。
