# Stress-tensor flows in four-dimensional single-scalar DBI theory

Working repository for a study of stress-tensor deformation flows in four-dimensional Dirac--Born--Infeld theory with one real scalar field and one Abelian gauge field.

## Repository structure

- `paper/` — manuscript source and submission-related files.
- `notes/` — detailed calculation notes with intermediate algebra and background explanations.
- `code/` — neural-network exploration, exact symbolic checks, and independent numerical validation.
- `data/` — numerical validation outputs used in the exploratory and analytic checks.

## Status

Work in progress. The repository is private while the analytic result and manuscript are being checked before public release.

## Reproducibility

The analytic identities are checked independently with SymPy exact arithmetic. A neural network is used as an exploratory tool to test whether the deformation generator can be represented as a function of stress-tensor invariants; the final analytic statements do not rely on the trained network.
